# 宿泊予約自動実行アプリ マニュアル

このアプリは、指定された時間に予約サイトへアクセスし、馬場光浩様の情報を自動入力して予約をサポートするツールです。

## 🚀 起動方法
1. ターミナルで以下のコマンドを実行します：
   ```bash
   python hotel_reservation_app.py
   ```
2. ブラウザで自動的に管理画面（Streamlit）が開きます。

## 📝 設定手順
1. **サイトURL**: 予約対象のURLを入力してください。
2. **宿泊希望日・人数**: カレンダーから日付を選択し、人数を入力してください。
   - ※入力後、**[Enter]キー**を押すか**入力欄の外をクリック**すると、右側の「最終確認パネル」が更新されます。
   - **AIによる自動入力 (必須)**: サイドバーに「OpenAI API Key」を入力してください。AI（GPT-4o-mini）がサイトの構造を解析し、入力項目を特定します。
3. **実行タイミング**: 予約の受付が開始される時刻を設定してください。
   - 時刻はキーボードから `10:00` のように直接入力できます。
4. **最終確認**: 右側の「📋 最終確認」パネル内の内容（サイト、実行時刻、宿泊日、人数）が正しいことを必ず確認してください。
5. **予約実行**: 「🚀 予約実行 (待機開始)」ボタンを押すと、指定時刻まで待機を開始します。

## 🛑 中断方法
- 実行中（待機中およびブラウザ動作中）は、**「⏹️ 停止」**ボタンが表示されます。
- このボタンを押すと、即座にブラウザが閉じられ、処理が安全に停止します。

## 💡 注意事項
- **自動確定は行いません**: フォーム入力までを自動化します。内容を確認し、最後の「予約確定」ボタンは手動で押してください。
- **不足情報の入力**: AIが「性別」や「チェックイン時間」など、事前に設定されていない項目をサイト側で見つけた場合、管理画面上に追加入力用のフォームが表示されます。指示に従って入力してください。
- **ブラウザ操作**: 自動入力完了後もブラウザは開いたままになります。内容を確認して、手動で予約を完了させてください。
