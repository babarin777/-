# 宿泊予約自動実行アプリ（高負荷・リトライ対応版） マニュアル

このアプリは、指定された時間に特定の宿泊予約サイトにアクセスし、自動的に個人情報を入力して予約をサポートするためのツールです。特に、アクセスが集中して繋がりづらいサイトでも、**最大2時間粘り強くリトライを繰り返す**ように設計されています。

## 1. 動作要件

このアプリを動かすには Python がインストールされている必要があります。

### 必要なライブラリのインストール
ターミナル（コマンドプロンプト）で以下のコマンドを実行してください。

```bash
pip install streamlit playwright playwright-stealth
playwright install chromium
```

## 2. アプリの起動方法

アプリのフォルダに移動して、以下のコマンドを実行します。

```bash
streamlit run hotel_reservation_app.py
```

実行後、ブラウザが自動的に開き、アプリの画面が表示されます。

## 3. 設定項目

### 基本設定（画面左側）
- **アクセスするサイトURL**: 予約したいページのURL。
- **宿泊希望日 / 利用人数 / 同行者名**: 予約に必要な情報を入力します。
- **実行スケジュールの設定**: 予約開始時間（例: 21:00:00）に合わせて設定します。

### 詳細設定
- **最大リトライ継続時間**: デフォルトで2時間に設定されています。この時間内は、エラーが出ても自動でアクセスを繰り返します。
- **カスタムCSSセレクタ**: 特定の入力欄が自動入力されない場合、エンジニア向けに詳細な指定が可能です。通常は空欄（`{}`）で問題ありません。

## 4. 実行の流れ

1. すべての情報を入力し、「🚀 待機開始 / 実行」ボタンを押します。
2. 指定した時間までカウントダウンが始まります。
3. 時間になるとブラウザ（Chrome）が起動し、サイトへのアクセスを開始します。
4. **混雑時の動作**:
   - サーバーエラー(500番台)や「混み合っています」という画面が出た場合、自動で数秒待機して再読み込みします。
   - 予約フォームが表示されるまで、何度でも（最大2時間）アクセスを試行します。
5. **自動入力**:
   - フォームが表示されたら、馬場様の「お名前」「メールアドレス」「電話番号」「住所」などを自動で入力します。
   - 姓・名の分割入力や、フリガナにも対応しています。
6. **最終確認**:
   - 入力が終わると、アプリ画面に「自動入力が完了しました！」と表示されます。
   - **予約の確定ボタンは自動では押しません。** 内容を必ず確認し、クレジットカード情報など必要な項目があれば補完して、ご自身で予約を確定させてください。

## 5. トラブルシューティング

- **ブラウザが起動しない**: `playwright install chromium` を実行したか確認してください。
- **入力されない項目がある**: サイト独自の特殊なフォームの場合、自動判定できないことがあります。その場合は手動で入力をお願いします。
- **途中で止まった**: 実行画面の「詳細ログ」を確認してください。エラー内容が表示されています。必要に応じてアプリを再起動してください。
