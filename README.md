# Excel 解析アプリ

このアプリケーションは、Excelファイルをアップロードし、自然言語でデータ解析を依頼できるブラウザベースのツールです。

## 主な機能

1. **Excelファイルのアップロード**: 任意のExcelファイル（.xlsx, .xls）をアップロードし、シートを選択して読み込むことができます。
2. **データプレビュー**: 読み込んだデータの先頭数行や、カラム情報、欠損値の状態などを確認できます。
3. **自然言語による解析**: OpenAI APIを使用することで、「売上の推移をグラフにして」「カテゴリ別の集計をして」といった日本語の指示でデータを解析し、グラフや表を生成します。

## セットアップと実行方法

### 1. 必要ライブラリのインストール

```bash
pip install -r requirements.txt
```

### 2. アプリケーションの起動

以下のコマンドを実行することで、依存ライブラリのチェックとアプリの起動を自動で行います。

```bash
python run_app.py
```

または、直接 Streamlit を使用して起動することもできます。

```bash
streamlit run excel_analyzer_app.py
```

起動後、ブラウザで `http://localhost:8501` にアクセスしてください。

## 起動しない場合のトラブルシューティング

1. **コマンドプロンプト/ターミナルのエラーを確認**: `run_app.py` を実行した際に表示されるエラーメッセージを確認してください。
2. **ポートの競合**: すでに他のアプリがポート 8501 を使用している場合、Streamlit は 8502, 8503... と自動的にポートをずらして起動します。コンソールに表示される URL を確認してください。
3. **ブラウザを手動で開く**: 自動でブラウザが開かない場合は、ブラウザのアドレス欄に `http://localhost:8501` を直接入力してください。
4. **依存ライブラリの再インストール**: `pip install -U -r requirements.txt` を実行して、最新のライブラリに更新してみてください。

## 使い方

1. 左側のサイドバーからExcelファイルをアップロードします。
2. 解析したいシートを選択します。
3. 高度な解析を行う場合は、サイドバーに OpenAI API Key を入力してください。
4. 中央のテキストエリアに解析したい内容を入力し、「解析実行」ボタンを押してください。

## 注意事項

- OpenAI API Key がない場合でも、基本的な統計情報の表示は可能です。
- セキュリティのため、信頼できるファイルのみをアップロードしてください。
