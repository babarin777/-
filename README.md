# Excel Q&A アプリ

Excelファイルをアップロードして、その内容についてAIに質問できるStreamlitアプリケーションです。

## 準備事項

### 1. ライブラリのインストール
以下のコマンドを実行して、必要なライブラリをインストールしてください。

```bash
pip install streamlit pandas openpyxl openai
```

### 2. OpenAI APIキーの取得
[OpenAIの公式サイト](https://platform.openai.com/)からAPIキーを取得してください。

## アプリの起動方法

ターミナルで以下のいずれかのコマンドを実行します。

### A. Pythonコマンドで直接起動（推奨）
```bash
python excel_qa_app.py
```

### B. Streamlitコマンドで起動
```bash
streamlit run excel_qa_app.py
```

実行後、ブラウザが自動的に開き、アプリが表示されます。

## 操作方法

1. **設定（サイドバー）**:
   - 左側のサイドバーにある「OpenAI API Key」欄に、取得したAPIキーを入力してください。
   - **Tip**: `excel_qa_app.py` ファイルの冒頭にある `OPENAI_API_KEY = "*****"` の部分を書き換えて保存すると、毎回入力する手間を省けます。
   - 必要に応じてモデル（gpt-4o または gpt-4o-mini）を選択します。

2. **Excelシートの入力**:
   - 「Browse files」ボタンを押すか、ファイルをドラッグ＆ドロップしてExcelファイル（.xlsx / .xls）をアップロードします。
   - 複数のシートがある場合は、分析したいシートを選択してください。
   - 「データのプレビューを表示」をクリックすると、読み込んだデータの内容を確認できます。

3. **質問内容の入力**:
   - 画面中央のテキストエリアに、データについて聞きたいことを入力します。
     - 例：「このデータの概要を教えてください」
     - 例：「売上が一番高い月はいつですか？」

4. **AIに質問する**:
   - 「AIに質問する」ボタンをクリックすると、AIが解析を開始し、回答を表示します。

## 補足
- **利用統計の無効化**: `.streamlit/config.toml` を作成済みですので、起動時の「Collecting usage statistics」というメッセージは表示されないようになっています。
- **セキュリティ**: 入力したAPIキーはメモリ上にのみ保持され、ファイルとして保存されることはありません。ブラウザを更新すると再入力が必要になります。
