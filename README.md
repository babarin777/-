# Excel 解析アプリ

このアプリケーションは、Excelファイルをアップロードし、自然言語でデータ解析を依頼できるブラウザベースのツールです。

## 主な機能

1. **Excelファイルのアップロード**: 任意のExcelファイル（.xlsx, .xls）をアップロードし、シートを選択して読み込むことができます。
2. **データプレビュー**: 読み込んだデータの先頭数行や、カラム情報、欠損値の状態などを確認できます。
3. **自然言語による解析**: OpenAI APIを使用することで、「売上の推移をグラフにして」「カテゴリ別の集計をして」といった日本語の指示でデータを解析し、グラフや表を生成します。

## セットアップと実行方法

### 1. 必要ライブラリのインストール

```bash
pip install -r requirements.txt
```

### 2. アプリケーションの起動

以下のコマンドを実行することで、依存ライブラリのチェックとアプリの起動を自動で行います。

```bash
python run_app.py
```

または、直接 Streamlit を使用して起動することもできます。

```bash
streamlit run excel_analyzer_app.py
```

起動後、ブラウザで `http://localhost:8501` にアクセスしてください。

## アプリが起動しない場合（PC側の設定確認）

アプリが起動しない原因の多くは、PCの環境設定にあります。以下の点を確認してください。

### 1. Pythonがインストールされているか
コマンドプロンプト（Windows）またはターミナル（Mac）を開き、以下のコマンドを入力してください。
```bash
python --version
```
エラーが出る場合は、[Python公式サイト](https://www.python.org/)からインストールし、インストール時に**「Add Python to PATH」**にチェックを入れたことを確認してください。

### 2. ライブラリが正しくインストールされているか
一部の環境では、セキュリティソフトや権限の関係でライブラリのインストールが不完全になることがあります。
`run_app.py` または `run_app.bat` を**管理者権限**で実行してみてください。

### 3. ポート（8501）の開放
会社などの制限されたネットワーク環境では、ポート `8501` がブロックされている場合があります。
- **解決策**: `run_app.py` の出力に表示される URL（例: `http://localhost:8505`）を直接ブラウザに入力してアクセスしてください。

### 4. Windowsの実行ポリシー
Windowsで `.bat` ファイルが動かない場合、右クリックして「プロパティ」を開き、一番下の「許可する」にチェックを入れて適用してください。

### 5. それでも解決しない場合
`run_app.py` を実行した際に表示される黒い画面（コンソール）のメッセージを確認してください。
- `❌ 未インストール` と出ている項目があれば、そのライブラリのインストールに失敗しています。
- `❌ エラー: アプリが予期せず終了しました` と出る場合は、表示されている詳細なエラー内容（Traceback）を教えてください。

## 使い方

1. 左側のサイドバーからExcelファイルをアップロードします。
2. 解析したいシートを選択します。
3. 高度な解析を行う場合は、サイドバーに OpenAI API Key を入力してください。
4. 中央のテキストエリアに解析したい内容を入力し、「解析実行」ボタンを押してください。

## 注意事項

- OpenAI API Key がない場合でも、基本的な統計情報の表示は可能です。
- セキュリティのため、信頼できるファイルのみをアップロードしてください。
