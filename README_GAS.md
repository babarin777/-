# 受注管理・分析ツールの使い方

このツールは、Googleスプレッドシート上で過去の案件データと最新のデータを比較し、分析結果とアドバイスを出力するものです。

## 1. スプレッドシートの準備

以下の3つのシートを作成してください。

### ① 「過去データ」シート / ② 「更新データ」シート
両方のシートで、1行目に以下のヘッダー（項目名）を正確に入力してください。
* `営業担当者`
* `取引先名`
* `案件名`
* `ステータス`
* `確度`
* `会計期間`
* `受注予定額`
* `受注予定年月`

※2行目以降にデータを入力してください。
※「取引先名」と「案件名」の組み合わせでデータを紐付けます。

### ③ 「分析結果」シート
（プログラムが自動生成するため、空の状態で構いません）

## 2. GASのセットアップ

1.  スプレッドシート上部のメニューから **[拡張機能]** > **[Apps Script]** を選択します。
2.  開いたエディタに、`order_management.gs` の内容をすべてコピー＆ペーストします。
3.  プロジェクトを保存（Ctrl+S または 💾アイコン）します。
4.  スプレッドシートの画面に戻り、リロード（再読み込み）します。

## 3. 実行方法

1.  スプレッドシートのメニューバーに **[受注管理]** というメニューが表示されます。
2.  **[受注管理]** > **[データ分析実行]** をクリックします。
3.  初回実行時は「承認」が必要です。画面の指示に従って許可してください。
4.  分析が完了すると、「分析結果」シートに以下の内容が出力されます。
    *   **停滞懸念**: ステータスが動かず、受注予定日が延びている案件。
    *   **大幅変更**: 確度、金額、時期に大きな変動があった案件。
    *   **アドバイス**: 確度が低い（D/E）案件や、停滞案件への具体的なアクション。

## 4. 分析のポイント

*   **確度D/Eの案件**: 停滞している場合、ステータスに応じた具体的なアドバイスが表示されます。
*   **大幅な変更**: 受注予定額が20%以上変動した場合などにアラートが出ます。
