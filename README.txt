Excelデータ解析アプリ トラブルシューティングガイド
=========================================

ブラウザで「接続が拒否されました」と表示される場合、以下の対策を順に試してください。

1. プロキシ設定の確認（特に重要）
--------------------------------
会社のネットワークでは、ブラウザのプロキシ設定が原因でローカル（localhost / 127.0.0.1）への
アクセスが遮断されることがあります。

対策：
- ブラウザの設定で「ローカルアドレスにはプロキシサーバーを使用しない」が有効か確認してください。
- または、別のブラウザ（Chromeの代わりにEdgeなど）を試してください。

2. IPアドレスでのアクセス
-------------------------
localhostの代わりに、マシンの実際のIPアドレス（例: http://192.168.1.10:8501）を使うと
解決する場合があります。
- `run_app.py` 実行時に表示される「ネットワーク経由」のURLを試してください。

3. セキュリティソフトの確認
---------------------------
Windows Defenderやアンチウイルスソフトが、Pythonによる通信をブロックしている場合があります。
- アプリ起動時に「Windows セキュリティの重要な警告」が出た場合は「アクセスを許可する」を選択してください。

4. ポートの競合
---------------
他のアプリが同じポート（8501）を使っていると起動できません。
- `run_app.py` は自動的に別のポートを探します。画面に表示されたポート番号を確認してください。

5. 実行環境の確認
-----------------
- システムディレクトリ（C:\Windows\system32）で実行しないでください。
- アプリのファイルがあるフォルダへ移動（cd）してから実行してください。
