【ニュースガジェット 起動方法のご案内】

Windowsをお使いの方は、特別なアプリをインストールする必要はありません。

■ 起動方法
1. このフォルダの中にある「run_news_gadget.bat」というファイルをダブルクリックしてください。
2. 自動的にガジェットが起動します。

※初回起動時に、青い画面（WindowsによってPCが保護されました）が出ることがありますが、その場合は「詳細情報」をクリックしてから「実行」を押してください。

■ 内容
・AI関連、再エネ、EVの最新情報をタブで切り替えて閲覧できます。
・「最前面に表示」にチェックを入れると、他のウィンドウに隠れなくなります。
・記事タイトルをクリックするとブラウザで記事が開きます。
・「日経優先」バッジがついた記事は、日本経済新聞の情報を優先的に表示しています。

■ ニュースが表示されない場合（「記事が見つかりませんでした」と出る場合）
社内ネットワークのセキュリティ制限により、通信が遮断されている可能性があります。
アプリ画面に表示される **「(詳細: ... )」** の内容を確認してください。

1. **「(詳細: RSS解析結果が空です。 内容: <html...)」** と出る場合：
   通信は成功していますが、会社のフィルタリング（i-FILTER等）により、Googleニュースの代わりに「ブロック画面（HTML）」が返されています。これはPCのセキュリティ設定によるもので、アプリ側からの回避は困難です。

2. **「(詳細: Googleの同意画面にブロックされました)」** と出る場合：
   Google側のクッキー確認画面で止まっています。再度「更新」ボタンを押すか、ブラウザで一度 Google ニュースを開いてから試してください。

3. **「(詳細: IWR Error / WC Error ... )」** と出る場合：
   プロキシ設定やSSL証明書の不一致により接続自体が拒否されています。

4. **「(詳細: 記事が見つかりません。 内容: )」** のように、内容が空の場合：
   プロキシが通信を空（0バイト）で返している可能性があります。

■ 解決のためのヒント
・ブラウザ（EdgeやChrome）で https://news.google.com/rss/search?q=AI が正常に（XML形式で）開けるか確認してください。ブラウザで開けない場合は、アプリでも取得できません。
・「Direct PC Access」を試みるため、PowerShell版（WebClient）へのフォールバックを実装済みです。

■ 補足（エンジニア向け）
・Python版（news_gadget.py）は `requests` と `feedparser` を使用します。
・PowerShell版（news_gadget.ps1）はOS標準機能のみで動作します。
