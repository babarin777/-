【ニュースガジェット 起動方法のご案内】

Windowsをお使いの方は、特別なアプリをインストールする必要はありません。

■ 起動方法
1. このフォルダの中にある「run_news_gadget.bat」というファイルをダブルクリックしてください。
2. 自動的にガジェットが起動します。

※初回起動時に、青い画面（WindowsによってPCが保護されました）が出ることがありますが、その場合は「詳細情報」をクリックしてから「実行」を押してください。

■ 内容
・AI関連、再エネ、EVの最新情報をタブで切り替えて閲覧できます。
・「ニュースを更新」ボタンで最新の状態に更新されます。
・記事タイトルをクリックするとブラウザで記事が開きます。

■ 社内網から接続できない場合
本アプリは社内プロキシやSSL診断（SSLインターセプト）環境でも動作するよう、以下の対策を施しています。
・システムプロキシ設定の自動利用
・SSL証明書検証エラー時の自動回避

もしニュースが表示されない場合は、画面に表示される「詳細」メッセージとあわせて以下の点をご確認ください：

1. **プロキシ設定**:
   ブラウザで Google ニュース（news.google.com）が開けるか確認してください。繋がらない場合は会社のネットワーク制限です。
2. **認証プロキシ**:
   ID/パスワード入力を求めるプロキシ環境では、自動取得が制限される場合があります。
3. **SSLデコード**:
   SSL通信の中身を検査するセキュリティ製品が導入されている場合、エラーになることがあります。本アプリでは回避を試みていますが、完全に防げない場合があります。
4. **取得時間**:
   ネットワーク環境により、初回取得に時間がかかる（10〜20秒程度）場合があります。

■ 補足（エンジニア向け）
・Pythonがインストールされている環境では、news_gadget.py を直接実行することも可能です。
  その場合は、pip install -r requirements.txt で必要なライブラリを導入してください。
